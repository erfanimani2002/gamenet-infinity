# 🎮 گیم‌نت اینفینیتی (GameNet Infinity)

اپلیکیشن وب مدیریت گیم‌نت / کافی‌نت — مدیریت کنسول‌ها، بیلیارد، سیستم‌های PC، کافی‌شاپ، مشتریان، بدهی‌ها، مسابقات و گزارش‌های مالی، همه در یک صفحه‌ی وب که به‌صورت آفلاین (Local-first) روی دستگاه خودتان اجرا می‌شود.

بدون نیاز به دیتابیس بیرونی، اینترنت یا هزینه‌ی سرور — تمام داده‌ها در همان مرورگر (IndexedDB) ذخیره می‌شوند و یک سرور کوچک Node.js فقط فایل‌های استاتیک را سرو می‌کند و پشتیبان‌گیری (backup) را مدیریت می‌کند.

---

## ✨ امکانات

- **مدیریت کنسول‌ها (PlayStation)** — شروع/پایان بلوک زمانی، محاسبه‌ی هزینه بر اساس نرخ ساعتی، نمایش هزینه‌ی زنده حین بازی
- **مدیریت میزهای بیلیارد** — همان منطق بلوک زمانی، مخصوص میزها
- **مدیریت سیستم‌های PC (کامپیوتر گیمینگ)**
- **رزرو شب‌مانی (Overnight)** — رزرو و تسویه‌ی حساب برای اقامت شبانه
- **کافی‌شاپ** — ثبت سفارش، منو، افزودن آیتم به جلسه‌ی مشتری
- **مدیریت مشتریان و باشگاه مشتریان (Customer Club)** — پروفایل، کیف پول، شارژ حساب
- **مدیریت بدهی‌ها (Debts)** — ثبت و تسویه‌ی بدهی مشتریان
- **جریمه‌ها (Penalties)**
- **خرید و انبار (Purchases & Inventory)**
- **مدیریت پرسنل (Staff)** و صندوق/شیفت
- **مسابقات (Tournaments)** — برگزاری تورنمنت، مسابقات، جوایز
- **گزارش‌های مالی (Reports)** — گزارش روزانه، تراکنش‌ها، ویرایش تراکنش‌های ثبت‌شده
- **پنل ادمین** برای تنظیمات کلی، نرخ‌ها، دسترسی‌ها
- **لاگ فعالیت‌ها (Activity Log)**
- **پشتیبان‌گیری خودکار/دستی (Backup)** از طریق سرور محلی
- **تقویم شمسی (Jalali)** برای نمایش تاریخ و ساعت

---

## 🧱 تکنولوژی‌ها

| بخش | تکنولوژی |
|---|---|
| فرانت‌اند | HTML + CSS + Vanilla JavaScript (بدون فریم‌ورک) |
| ذخیره‌سازی داده | IndexedDB (مرورگر) |
| بک‌اند | Node.js (`http` خام، بدون فریم‌ورک/پکیج بیرونی) — فقط برای سرو فایل‌ها و ذخیره‌ی بکاپ |
| فونت | فونت فارسی محلی (پوشه‌ی `fonts/`) |
| خواندن اکسل | `lib/xlsx.full.min.js` (SheetJS) |

پروژه هیچ `package.json` یا وابستگی npm ندارد — فقط Node.js نصب‌شده روی سیستم لازم است.

## 🚀 راه‌اندازی

### پیش‌نیاز
- [Node.js](https://nodejs.org) (هر نسخه‌ی نسبتاً جدید، چون فقط از ماژول‌های داخلی استفاده شده)
- نصب بودن مرورگر FireFox روی سیستم

### روش ۱ — ویندوز (خودکار)
1. اگر Node.js نصب نیست، فایل `install-node-windows.bat` را اجرا کنید.
2. فایل `start-app.bat` را اجرا کنید — سرور را بالا می‌آورد و آدرس را در فایرفاکس باز می‌کند.

### روش ۲ — دستی (هر سیستم‌عاملی)
```bash
node server.js
```
سپس در مرورگر به آدرس زیر بروید:
```
http://127.0.0.1:3000
```

> سرور روی پورت `3000` و فقط روی `127.0.0.1` (لوکال) اجرا می‌شود.

## 💾 داده‌ها و پشتیبان‌گیری

- تمام داده‌ها (مشتریان، جلسات، تراکنش‌ها و ...) در **IndexedDB مرورگر** ذخیره می‌شوند؛ یعنی اگر کش/دیتای مرورگر پاک شود، داده‌ها از بین می‌روند.
- برای جلوگیری از این ریسک، اپ امکان **پشتیبان‌گیری** دارد: با درخواست `POST /api/backup`، یک فایل JSON از کل دیتابیس در پوشه‌ی `backups/` (که خودکار ساخته می‌شود) ذخیره می‌شود.
- توصیه می‌شود به‌صورت دوره‌ای از بخش پشتیبان‌گیری در اپ، بکاپ بگیرید.

## 🧩 منطق محاسبه‌ی هزینه (بلوک‌های زمانی)

بخش‌های کنسول، بیلیارد و PC از یک الگوی مشترک «بلوک زمانی» (`timeBlocks`) استفاده می‌کنند:

- هر بلوک با `startTime` شروع می‌شود و نرخ ساعتی (`rate`) دارد.
- وقتی بلوک بسته می‌شود، `endTime` ثبت و `price` بر اساس `hours × rate` (با رند‌شدن طبق تنظیمات `roundingUnit`) محاسبه می‌شود.
- تا وقتی بلوک باز است، مدت‌زمان و هزینه به‌صورت زنده (بر پایه‌ی `Date.now()`) در صفحه نمایش داده می‌شود.
